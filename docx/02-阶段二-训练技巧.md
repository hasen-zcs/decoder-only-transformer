# 阶段二：训练技巧（LR 调度 + 梯度裁剪 + 权重共享）

## 目标

不改架构，改进训练配方：学习率调度、梯度裁剪、权重共享；顺带 4 层 → 8 层。

## 三个技巧

1. **LR 调度**（`train_mini.py::get_lr`）：0→1e-3 线性 warmup 200 步，余弦衰减到 1e-4；每步设置 param_group 的 lr，每 100 步打印 `lr`
2. **梯度裁剪**：`clip_grad_norm_(params, 1.0)`，打印 `grad_norm`
3. **权重共享**：
   ```python
   self.lm_head = nn.Linear(config.n_embd, config.vocab_size, bias=False)
   self.lm_head.weight = self.embedding.token_embedding.weight
   ```
   输出层与输入层共用一张表：省 ~543k 参数，且"预测某个字"变成"残差流与该字自身向量的点积"
4. （并行改动）`n_layer 4 → 8`；`Config.py` 新增 `base_lr / min_lr / warmup_steps / grad_clip` 四个字段

## 参数量（8 层共享版，估算）

1. **lr 全程恒定 1e-3** → 这次 run 没走 warmup+cosine（调度代码是之后才写进脚本的，或当时未启用）

→ **结论：这份日志其实是"8 层 untied、恒定 lr"的中间 run**（4→8 层之后、权重共享实现之前），不是阶段二配方。**阶段二配方（tied + 调度 + 裁剪）从未正式跑过。**

## warmup 讨论

- 200 步 = 1 万步的 2%，处于常见 1%~10% 区间，**不少**；Adam 的偏差校正本身处理早期动量噪声，warmup 对 Adam 的重要性低于 SGD
- 判断"不够"靠观察不靠感觉：前 200 步 loss **向上跳** + grad_norm 长期顶 1.0 → 提到 500 重跑；没有这种信号就不动
- 纪律：warmup 是配方的一部分，阶段二/三必须同值，否则差异无法归因
