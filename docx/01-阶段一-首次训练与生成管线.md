# 阶段一：首次训练 + 生成管线打通

## 目标

把"训练 → checkpoint → 生成"整条链路跑通：先训一个 4 层小模型（1000 步），并让它能生成像小说的文本。

## 数据管线（项目早期建好的地基）

- `data/novel.txt`（约 27.6 万行网文）→ `data/txt_clear.py` 清洗 → `data/train.bin` / `data/val.bin`（uint16 编码）
- 字符级词表 4242 字（`data/vocab.json`），tokenizer：`model/Tokenizer.py`（`MyTokenizer`）
- `Dataset.py`：`MyDataset` 随机切 batch 个 (x, y) 窗口，y 为 x 左移一位（下一字符预测）
- `model/Config.py`：vocab 4242 / block 128 / n_embd 128 / ffn 256 / 4 头 / batch 64 / dropout 0.1

## 本阶段改动

1. **首次训练（4 层）**：Post-LN + LayerNorm + 可学习位置嵌入，lm_head **不共享**（默认 Linear、小初始化），恒定 lr 1e-3，1000 步
   - 结果：train loss ≈8.4 → **3.80 @ step 999**；checkpoint `checkpoints/step_latest_4layers.pt`
   - 注意：初始 loss ≈8.35 = ln(4242) 是"untied + 小 Linear 初始化"的**正确**指纹——这条直觉后来在阶段三被误用于共享模型，踩了坑（见 03）
2. **`train_mini.py` 续训修复**：全新启动时 `checkpoint` 未定义 → NameError。修法：`start_step = 0` 默认值；`checkpoints/step_latest.pt` 存在时加载 model + optimizer 状态继续训
3. **`generate.py` 修复**：原来构建模型后**没有加载任何 checkpoint**（随机权重生成 → 纯乱码/复读）。改为加载 checkpoint（`weights_only=True`）
4. **`GPT.generate` 加采样**：原来纯 argmax → 文本循环复读。加 `temperature=0.8` + `top_k=50` 截断 + `multinomial` 采样

## 结果

- 1000 步 / 8.19M token（64×128×1000），train loss 3.80
- 4 个 prompt × 2000 token → `output/生成结果.txt`：能读出连贯中文，但重复仍多（4 层 + 1000 步容量不足，属正常）

## 已知问题 / 移交

- 该阶段没有跟踪 val loss（旧脚本只在结束时评一次）→ 从阶段二起每 100 步打印 val
- argmax 生成差 → 采样（本阶段已修）
- 续训会重跑最后一个已存 step 一次（off-by-one，列入 README 遗留清单）
