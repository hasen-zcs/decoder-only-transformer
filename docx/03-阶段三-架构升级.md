# 阶段三：架构升级（Pre-LN + RMSNorm + RoPE）

## 目标

把架构升级到现代标准，并与阶段二形成受控对比（同 8 层、同配方、仅架构不同）：

1. **Post-LN → Pre-LN**：`x = x + Sub(RMSNorm(x))`，残差流保持干净，训练更稳
2. **LayerNorm → RMSNorm**：只归一化 RMS 尺度，不做均值中心化、无 bias，更快
3. **可学习位置嵌入 → RoPE**：对 q/k 旋转注入相对位置，无位置参数表，上下文长度变成纯配置项（收益在阶段四兑现）
4. 权重共享保留（阶段二起）

## 改动（文件级）

`model/model.py`：
- `GPTEmbedding`：只保留 token embedding，**删掉位置表**
- `GPTLayer`：`rms_norm1/2`（RMSNorm），Pre-LN：`x = x + attn(norm1(x))`，`x = x + ffn(norm2(x))`；attention 传入 `cos/sin`
- `GPT`：末尾 norm 改 `RMSNorm`；`lm_head` tied（bias=False）；`precompute_freqs_cis(head_dim=32, end=config.block_size)` 注册为 buffer `freqs_cos / freqs_sin`
- `forward`：`cos = self.freqs_cos[:T]` 按实际长度切片
- `generate`：保留最后 `block_size` 个 token，temperature 0.8 + top_k 50（阶段一起）

`model/structure.py`：
- `RMSNorm(dim, eps=1e-5)`：`x * rsqrt(mean(x²)+eps) * weight`
- `precompute_freqs_cis(dim, end, rope_base=1e6)`：`θ_i = pos / base^(2i/dim)`，半重复布局 `cat([cos, cos])`
- `apply_rotary_pos_emb`：rotate_half + `cos.unsqueeze(1)`，**transpose 之前**（[B,T,H,D] 布局）作用于 q/k
- `MultiHeadAttention.forward(query, key, value, mask=None, cos=None, sin=None)`：q/k 先过 RoPE 再进入注意力
- `repeat_kv`：GQA 预留函数（本阶段未用）

## 初始 loss 的 smoke test 与"102 之谜"（本阶段最有教育意义的部分）

Smoke test 目的：大训练前确认随机初始化模型 forward 健康。期望值经历三轮修正：

| 轮次 | 期望 | 问题 |
|---|---|---|
| 1 | loss ≈ 8.35 = ln(4242) | ❌ 那是 **untied** 模型的指纹（阶段一直觉）；共享模型的 logits 不小 |
| 2 | loss ≈ 40 | ❌ 理论：共享 → 每位置 logit ≈ N(0, 128)，4242 个样本的 max ≈ 3.7σ ≈ 42；但实测 **102.27**，与该理论矛盾（干净高斯的上界 ≈ max + ln V ≈ 50） |
| 3 | **loss ≈ 100（自尖峰）** | ✅ 所有数据自洽，见下 |

**探针数据（模型各部分全部健康）：**
- 嵌入：元素 std 1.005，行范数 11.34（≈√128，N(0,1) 正常）
- 逐层残差 std：1.04 → 1.27（温和随机游走，8 层正常）
- 最终 norm 后：元素 std 0.999（单位 RMS ✓）
- logits 全局 std：11.37（≈√128 ✓）
- lm_head 行范数 11.30 ≈ 嵌入行范数（共享生效 ✓）

**异常定位：**
- 逐行 logit max 均值 = **101.9**（9σ！），max/std = 8.96（纯高斯应 3.6~3.8）→ 每行必有一个 ≈100 的离群 logit
- 对照组"纯随机矩阵 h@e.T"loss = **41.6** → 理论没错
- 嵌入表行范数 top10 = 13.8~13.4，**无胖行** → 表干净
- → 唯一剩下的嫌疑：**隐状态 h 与表行不独立**

**两个被探针否掉的假设：**
- "胖行"（个别嵌入行范数异常大，经共享坐在输出端顶高所有位置）：被行范数 top10 否掉
- "公共常量方向"（所有位置的 h 共享同一方向，同一 token 恒赢）：被 top1 token 分布否掉——512 个位置没有任何 token 出现 100 次以上，argmax 随位置变化

**真相 —— 自尖峰（self-spike）：**
1. 随机初始化时各层输出远小于嵌入，残差流被输入主导：`h_t ≈ e_{x[t]} + 小扰动`（残差网络的正常初始状态，探针②的 1.04→1.27 正是"嵌入占大头"的体现）
2. 权重共享 ⇒ lm_head 就是这张表 ⇒ 每个位置对**当前 token 自己**的 logit = `h_t·e_{x[t]} ≈ ‖e‖² ≈ 100~130`，远高于其他 token 的高斯 max（≈42）
3. 于是每位置 max ≈100 → loss ≈102；且 **argmax = 当前 token**，随位置变化 → top1 分布天然平坦
4. 验证：`(logits.argmax(-1) == x).float().mean() = 1.0`，完美吻合，全案结束

**数学上界（为什么"干净"不可能给出 102）：**
对任意位置，`loss = max(logit) − logit_目标 + log(Σe^(logit−max)) ≤ max + ln(4242)`。
干净高斯行 ⇒ max ≈ 3.7σ ≈ 42 ⇒ 上界 ≈ 50。loss 102 必然来自"该位置有一个被特殊 token 钉在 ≈100 的 max"——即自尖峰。

**修正后的 smoke 指纹（以此为准）：**
```python
x = torch.randint(0, config.vocab_size, (4, 128))
logits, loss = gpt(x, x.roll(-1, dims=1))
print(loss.item())                              # 期望 90~110（参考值）
print((logits.argmax(-1) == x).float().mean())  # 期望 ≈ 1.0（真探针，跌破 = forward 有问题）
```

**可选优化（本阶段未做）：** 自尖峰根源 = 嵌入初始化 N(0,1) 偏大 + 共享。GPT-2 用 N(0, 0.02) 初始化嵌入，初始 loss 回到 ≈8.4，开局曲线更平滑。受控实验要求各阶段初始化一致，故不动；留作后续选项。
